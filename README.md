## Producing a Clean LVS Result 

#### Prerequisites
- [Xschem](http://repo.hu/projects/xschem/xschem_man/install_xschem.html), [Magic](https://github.com/rtimothyedwards/magic), and [Netgen](https://github.com/rtimothyedwards/netgen) are installed
- Sky130 PDK installed (via [ciel](https://github.com/fossi-foundation/ciel))
- **inverter.sch** schematic and **sky130_fd_sc_hd__inv_1.gds** file are downloaded from **LVS_RESOURCES**

#### Extracting Spice Netlists 

##### Xschem 
- open the schematic in Xschem using command ```xschem inverter.sch``` in terminal
- Set the netlist format by navigating to **Options -> Netlist format/Symbol mode -> Spice netlist**
- Click the **'Netlist'** button at the top right of the menu tool bar
- Xschem netlists are automatically imported to the **/.xschem/simulations** directory

##### Magic 
- Open the layout in magic using command ```magic sky130_fd_sc_hd__inv_1.gds``` in terminal
- In the Magic integrated tcl console, execute ```extract all```, then execute ```exttospice```
- Magic netlists are automatically imported to the current working directory

#### Performing the LVS 
- Download the **inverter.spice** and **sky130_fd_sc_hd__inv_1.spice** file or use the extracted netlists from the steps above
- Open netgen from the terminal by executing ```netgen``` to launch the console window
- Run the LVS at the console window prompt by executing ```lvs "inverter.spice inverter" "sky130_fd_sc_hd__inv_1.spice sky_130_fd_sc_hd__inv_1"```
- After LVS has been performed you should see at the end of it's input:

   ```Final result: Circuits match uniquely. LVS done.```
  
#### Analyzing the Results
- The complete output results are dumped ot a file generated by netgen called **comp.out**
- The expected complete output file can be found in [LVS_RESOURCES](https://github.com/madeline-microalchemy/EDA-helloworld/tree/main/LVS_Resources)
- **Comp.out** displays a side-by-side comparison of the two netlists decomposed
